# Configuration

- `VITE_API_BASE_URL` — backend base URL (không hard-code)
- `VITE_API_TIMEOUT_MS` — default 15000
- `VITE_USE_MOCK_FIXTURES` — dev only fallback
- `VITE_PUBLIC_REGISTRATION_ENABLED` / `PUBLIC_REGISTRATION_ENABLED` — gate /register

Không commit secret/JWT/password/private key — chỉ placeholder như `JWT_SECRET=<replace-me>`.

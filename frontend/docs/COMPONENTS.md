# Components

Nguồn: `src/components/ui/` + `src/index.css`.

- Primitives: `Button`, `Input`, `Select`, `Table`, `Dialog`, `Alert`, `Badge`, `Spinner`, `Skeleton`, `EmptyState`, `Breadcrumb`, `Drawer`, `Toast` (`ToastProvider` + `useToast`).
- Design tokens trong `index.css` (`--background`, `--surface`, `--success`, `--warning`, `--danger`, `--info`, `--navy`, ...).
- Patterns: loading (Skeleton) / empty / error (ApiError + correlation `c8f4-...`) / toast / drawer / confirm dialog / pagination / unsaved guard.

UI Kit demo ở `/dev/ui-kit`.
